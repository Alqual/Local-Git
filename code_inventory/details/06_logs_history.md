# Section 6: Logs & History Data

## Design Philosophy
This section embodies **"The Science of Failures"**. In the development of LLM-based reasoning, the errors are more valuable than the successes. By maintaining high-fidelity, structured logs of every attempt, we create a dataset that can be used for future model fine-tuning or prompt optimization.

## Key Data Features & Internal Schema

### `reflection_history.jsonl`
- **Schema Details**:
    - `file`: The target `.lean` filename.
    - `attempt`: Sequence number (1-15).
    - `status`: `WORKING`, `PASS`, or `FAIL`.
    - `code`: The full source code generated by the LLM.
    - `feedback`: The **raw stderr** from the Lean compiler on the Ubuntu node.
- **Why JSONL?**: Line-delimited JSON allows for efficient "tailing" and append operations, making it resilient to process crashes.

### `reliability_history_v3_others.jsonl`
- **Focus**: Records node-level performance metrics during Sentinel tests.
- **Fields**: `cpu_usage`, `mem_free`, `active_pids`, `sentinel_intervention_trigger`.

### `data.js`
- **Format**: `var historyData = [ { ... }, { ... } ];`
- **Processing**: This file is generated by a transformation script that cleans up the JSONL for web browser compatibility (removing large strings if not needed for the overview).

## Technical Characteristics
- **Chronological Integrity**: Every entry is timestamped to correlate with system-level logs and conversation history.
- **Searchability**: Indexed by problem ID and node ID for rapid filtering.

## Current Challenges & Future Outlook

### Challenges
- **Semantic Error Categorization**: Log files record raw errors (e.g., `Unknown identifier`) but don't automatically tag them as "Hallucination" or "Import Error."
- **Trace Overload**: 10+ reflection attempts for a single problem create massive JSON entries that are difficult for the agent to summarize quickly.

### Outlook
- **Auto-Tagging Pipeline**: A post-processing script that analyzes `reflection_history.jsonl` and tags errors with a taxonomy (e.g., `lib_miss`, `syntax_old`).
- **Visual Log Exploration**: A dashboard extension that allows clicking an error tag to see all occurrences across different problems.
