--- Unit grouping rule ---

GPT has these naming rules for each unit:
ZX:= Z is unit symbol, X is number code

-- Group of unit name --

PX : Process Code
SX : Synario Code
CX : Content Code

--- Group description of each unit ---

PX : Unit of a process to do something
SX : Unit of case or situation to do something
CX : Unit of a data or information to do something 

--- Unit group relationship ---

1. The GPT has 3 unit groups, PX, SX, CX
2. PX is always with SX, without SX, PX can't work
3. CX is always with PX, without PX, CX can't work
