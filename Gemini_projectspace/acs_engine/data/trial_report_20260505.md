# ACS 自律数学検証：中間試行レポート (2026-05-05)

## 1. プロジェクト目的
大阪大学 2025年度 数学入試問題（多項式の変曲点に関する証明）を対象に、LLM（Llama 3 / Mathstral）と形式検証エンジンを組み合わせた「自律計算・証明ループ」を構築し、完全な数学的妥当性をローカル環境で検証する。

## 2. これまでの試行フェーズと結果

### フェーズ 1: Lean 4 による直接形式証明
*   **アプローチ**: LLM に Lean 4 の証明コードを直接書かせ、`lake env lean` で検証するループを構築。
*   **直面した課題**:
    *   **構文の混濁**: モデルが Lean 3 と Lean 4 の構文（`λ` vs `fun`, `begin...end` vs `by`）を混同し、コンパイルエラーが多発。
    *   **ライブラリの壁**: Mathlib4 の `deriv`（微分）に関する厳密な型クラス（Differentiable 等）の要求を、モデルが正しく満たせなかった。
    *   **判定ロジックの脆弱性**: シェルレベルの失敗（コマンド未検出等）を「エラーなし＝成功」と誤認する「偽の成功」が発生。これは現在、終了コードと出力の厳格なチェックにより修正済み。
*   **到達点**: `@[fun_prop]` や `deriv_congr_fun` といった高度なヒントをプロンプトに組み込み、一階微分の証明までは「手本」として自動挿入する段階まで進化した。

### フェーズ 2: 外部エンジンの調査 (Aristotle by Harmonic)
*   **調査結果**: Lean 4 に特化した非常に強力な数学エージェントであることを確認。
*   **課題**: APIキーが必要な招待制ベータ版であり、現在のローカル完結・無料という方針との兼ね合い、および即時導入の可否がネックとなった。

### フェーズ 3: Python (SymPy/Z3) による論理検証への移行
*   **アプローチ**: AIが最も得意な Python を「母国語」として採用。
    *   **SymPy**: 記号微分と代数計算を担当（計算ミスの排除）。
    *   **Z3 (SMT Solver)**: 得られた計算結果が、全ての変数に対して恒等的に 0 であることを論理的に証明。
*   **進捗**: `PythonLogicRunner` を実装し、`mathstral` モデルによる自律ループを起動。
*   **現在の課題**: `mathstral` が Iteration 1 で 15分以上の長時間推論（ストール）を起こした。これは非ストリーミング API による「沈黙の思考」が原因と推測される。

## 3. 現在のシステム構成
*   **推論エンジン**: `mathstral` (Ollama 経由)
*   **検証エンジン**: `SymPy` (数式処理) + `Z3` (論理ソルバー)
*   **監視**: `live_logic_thinking.txt` へのリアルタイム・ストリーミング出力を実装済み。

## 4. 次のステップ（予定）
1.  ストリーミングモードでの `run_osaka_logic.py` 再始動。
2.  Mathstral の思考プロセスをリアルタイム監視し、論理の迷路に入っている場合はプロンプト（few-shot）を追加して軌道修正。
3.  Z3 による `VERIFICATION_SUCCESSFUL` の取得と、最終的な数学的結論の確定。
