# 指示プロンプト: Neuro-Plastic Database (NPDB) プロジェクト

## 📝 プロジェクト概要
既存の静的なデータベース構造（Relational, NoSQL, Graph）の限界を超える新しいパラダイムとして、生物の脳の記憶構造（可塑性と忘却）を模倣した動的データベース「Neuro-Plastic Database (NPDB)」のコンセプト構築とプロトタイプ実装を行ってください。

## 🎯 具体的な指示内容

1. **コンセプト定義とアーキテクチャ設計**
   - 既存データベースのトレンド（Vector DB, Graph DB等）を調査しつつ、それらと差別化できる「使用頻度に応じた動的な自己組織化（Neuro-Plasticity）」の概念を定義すること。
   - データのノード（Neuron）と結合（Synapse）のアーキテクチャを設計すること。
2. **コアアルゴリズムの実装**
   - 以下2つの生物学的な挙動をアルゴリズムとして落とし込むこと。
     *   **Hebbian Learning (ヘッブ学習)**: 同時あるいは頻繁に検索（発火）されるデータ間の結合を強化する仕組み。
     *   **Decay & Prune (忘却と剪定)**: 時間経過とともに結合が減衰し、一定の閾値を下回った関連性を自動的に削除する仕組み。
3. **Pythonによるプロトタイプ開発 (npdb.py)**
   - 提案したアーキテクチャとアルゴリズムをシミュレートするPythonのプロトタイプコードを実装すること（バージョンを重ねて改良してよい）。
4. **テストシナリオの実行と検証**
   - データを投入し、特定のクエリによって意図通りに「関連性が強化されるか」、またスリープサイクル（時間経過）によって「ノイズが排除されるか」を検証すること。
5. **研究ステータスレポートの作成**
   - 上記の検証結果やコスト（本件は無料環境で実施想定）、今後の課題をまとめたMarkdownおよびHTML形式のレポートを出力すること。

## 👥 期待されるシステム/エージェントの役割
- 市場トレンド調査およびNPDBの新規パラダイム（忘却・可塑性）の理論構築を行うこと。
- Pythonを用いた技術的なプロトタイプ実装、ロジックのコーディングを担当すること。
- テストシナリオを構築し、プロトタイプが意図した「自己組織化」を達成できているか品質を検証すること。
