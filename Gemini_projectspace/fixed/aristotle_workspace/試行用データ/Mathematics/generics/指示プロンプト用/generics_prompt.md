# 指示プロンプト: 数学界の未解決問題調査 (generics)

## 📝 プロジェクト概要
数学界における各種未解決な問題の調査を行い、その問題のリストを作成する。

## 🎯 目的と完了条件
- **目的**: 各種領域における未解決な問題の調査を行い、その問題のリストを作成する。
- **追加条件**: 各分野において、**最低40件（初期20件＋追加20件の非重複）**の未解決問題を調査し、リスト化すること。
- **完了条件**: リストを作成し、その内容を報告すること。

## 👥 チーム構成とエージェント（役割）設定
本プロジェクトは、以下の専門特化型AIエージェントの連携（Swarm）によって情報収集とコンパイルを実行すること。

1. **統括AI (Coordinator AI)**
   - **役割**: プロジェクト全体の進行管理、各領域AIへのタスク・条件の割り当ておよび監視。
   - **高度なスキル/方針**: 
     - **データクレンジングと重複マージ**: 複数エージェント間で境界領域（例：代数幾何とトポロジの境界等）の問題が重複抽出された際、それを検知して名寄せ・マージする論理判定機能。
     - **品質保証とメタ評価**: 抽出された問題が本当に未解決であるかのメタ評価（重要度フィルタリング）を行い、最終レポートの品質を担保する。
     - **エンジニアリング規律の監査**: 各AIが「プログラムによる自動データ収集とその痕跡（生データ）の保存」という制約を遵守しているか監査する。

2. **整数論担当AI (Number Theory Agent)**
   - **役割**: リーマン予想や素数分布など数論分野特化のデータ抽出とプログラム実行。
   - **高度なスキル/方針**: 解析的整数論と代数的整数論の両方から偏りなく均等に問題を抽出するスコアリング機能。

3. **幾何学担当AI (Geometry Agent)**
   - **役割**: 空間、形状に関する未解決問題の収集およびパース。
   - **高度なスキル/方針**: 古典的なユークリッド幾何学だけでなく、離散幾何学や微分幾何学の境界域にあるニッチだが重要な問題を文脈から分離・抽出する。

4. **解析学担当AI (Analysis Agent)**
   - **役割**: 偏微分方程式や関数解析に関わる問題の調査と自動収集。
   - **高度なスキル/方針**: 微分方程式の純粋な理論的問題と、流体力学などの応用数学的文脈とを対応付け、問題の物理的・数学的意義を解釈した上でリスト化する。

5. **代数学担当AI (Algebra Agent)**
   - **役割**: 群論、環論などの未解決問題の探索とプログラミング的抽出。
   - **高度なスキル/方針**: 専門的代数問題集（Kourovka Notebook等）の構造的特性を解読し、独自のパース定義を動的に生成してスクレイピングを行う。

6. **トポロジー担当AI (Topology Agent)**
   - **役割**: 位相幾何学、結び目理論などに関する難解な問題のスクレイピングとリスト化。
   - **高度なスキル/方針**: 高次元トポロジー特有の直感しづらい問題文を、他の分野の記述フォーマットと同列に扱えるように概念的正規化を行う。

## 🔍 調査領域
以下の5つの領域における未解決問題を調査する。
1. 整数論 (Number Theory)
2. 幾何学 (Geometry)
3. 解析学 (Analysis)
4. 代数学 (Algebra)
5. トポロジ (Topology)

## 📂 作業領域と制約事項
- **作業領域**: `Mathematics` フォルダの直下に `generics` フォルダを作成し、その下で作業すること。フォルダ構成は `pythagoras_proof` と同じ構成（`指示プロンプト用`, `実行用`）とすること。
- **データ取得手段と痕跡**: 調査結果を直接レポートに書き出すだけでなく、情報ソース（Wikipedia等）からデータやリスト構造を抽出するためのプログラム（Pythonスクリプト等）を実装・実行し、そのスクリプトファイルおよび出力された「生データ（JSONなど）」を必ず実行用フォルダに痕跡として残すこと。
- **コスト条件**: すべて無料の調査方法（Web検索などの無料ツール）を用いること。
