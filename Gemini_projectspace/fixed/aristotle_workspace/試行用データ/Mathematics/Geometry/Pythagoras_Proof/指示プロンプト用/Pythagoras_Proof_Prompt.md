# 指示プロンプト: ピタゴラスの定理の新規証明と形式化プロジェクト

## 📝 プロジェクト概要
初等幾何学の枠組みの中で、既存の標準的な証明（ユークリッドの面積再配置やアインシュタインの相似な三角形のアプローチなど）とは異なる、ピタゴラスの定理の新しい証明方法を調査し、形式化（Formalization）を行ってください。

## 🎯 具体的な指示内容

1. **内接円を用いたアプローチの探求**
   - 直角三角形の「内接円の性質」と「面積計算」に基づいた証明アプローチを具体的に調査すること。
2. **Lean 4による形式化 (Formalization)**
   - Agent Betaを中心として、発見した証明をLean 4で論理的・数学的に厳密にフォーマル化し、コンパイルを通して検証すること。
   - 循環論法（アプローチの中でピタゴラスの定理の結論を前提とするような論理）に陥らないよう注意すること。
3. **コスト管理と監視**
   - Agent Gamma（Accountant）は、プラグインやAPIの利用コストを継続的に監視すること。
   - もし実通貨の費用が発生する状況になった場合は、**直ちにオペレーションを停止**し報告すること。
4. **PDFレポートの生成**
   - 証明の開発および検証が完了したら、以前の研究出力と同様のアプローチでサマリーレポートをPDF形式で生成すること。
5. **追加タスク（後半セッション）**
   - プロジェクトの締めくくりとして、さらにもう一つの独立した証明法（例えば「ガーフィールド大統領の台形証明法」など）についても調査・形式化し、レポートを出力すること。

## 👥 エージェントの役割定義
- **Agent Alpha (Proposer)**: 仮説の生成、潜在的な証明戦略（内接円法や台形法）の立案を行う。
- **Agent Beta (Verifier)**: 論理的整合性の確認、Lean 4コードの作成・コンパイルステータスの確認、循環論法の排除を行う。
- **Agent Gamma (Accountant)**: リソース使用量、プラグインコストの追跡、効率性レポートの作成を担う。
