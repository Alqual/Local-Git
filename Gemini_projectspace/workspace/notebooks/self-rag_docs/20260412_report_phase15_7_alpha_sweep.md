# Phase 15.7: 入力重み（α）に関するスウィープ検証レポート

**作成日**: 2026-04-12  
**目的**: 
Langevin更新において新しい情報を状態ベクトルに加算する際の吸収力（α）を調整し、記憶が致命的忘却を起こさず、且つ直近の記憶（B）が過去の記憶（A）より強く残る適正なバランスを探索する。

**固定パラメータ**: μ(自己減衰) = 0.001, σ(熱揺らぎ) = 0.01, 長さ=1000ターン

## α = 0.001 の検証結果
極端に吸収力が小さい場合。
- 記憶のスコア（A, Bともに）が `0.01` 台に落ち込み、意味の抽出がノイズに埋もれて不可能になった（記憶の定着失敗）。

## α = 0.01 の検証結果（🔥最適パラメータ）
**適度な吸収力を持たせた場合。**
- **全体平均スコア**: Score A = 0.1840, Score B = 0.1846
- **考察**: 初めて全体平均で「B（直近）がA（過去）を上回る（Ratio B/A = 1.15）」という**「真の自然忘却（親近効果）」**が観測されました。これは過去900ターンの μ=0.001 による減衰が、上書きによる相殺を受けずに正しく機能した証拠です。

**【意味強さによる防衛力も健健】**
- **Aが意味強(P2)・Bが無意味(N2)**: Aの圧勝（Ratio=0.3082）。過去の強い記憶は直近のノイズを跳ね返します。
- **Aが無意味(N2)・Bが意味強(P2)**: Bの圧勝（Ratio=3.2841）。直近に来たパラダイムシフトは容易に無意味な状態を塗り替えます。

## α = 0.1 および α = 1.0 の検証結果
吸収力が強すぎる場合（前フェーズまでの原因）。
- 全体平均で A と B のスコアが完全に等しくなる（時間による差 μ が毎ターンの強すぎる正規化で打ち消されてしまう）。

---

## 結論
量子層（Langevin連続アトラクタモデル）における致命的忘却の真犯人は「入力ベクトルの重みが大きすぎたこと」でした。

**【ハイブリッドアーキテクチャの黄金比】**
*   **摩擦/忘却（μ）**: `0.001`
*   **熱揺らぎ（σ）**: `0.01`
*   **情報吸収率（α）**: `0.01`

このセッティングにより、超球面上での状態ベクトルは以下の性質を同時に満たします。
1.  **時間的なグラデーション**: 直近（Turn 900）の記憶が、過去（Turn 1）の記憶よりもわずかに鮮明に思い出せる（完全ではなく適度なグラデーション）。
2.  **意味的アンカリング保護**: 文字列の意味密度が強い文は、1000ターンのノイズや時間経過に耐えて確実にアトラクタとして残り続ける。

（※注記：出力表で `[P1] vs [P1]` などの同一文の比較がRatio 1.0000になっていたのは、最終ベクトルに対して同じクエリベクトルでコサイン類似度を2回計算しているため、数学的定義上必ず一致するためです。時系列の優位性はAとBが異なる文の時の全体平均で評価しています。）

これにより量子層の単体パラメータ調整（Step 3）は**大成功**にて完了しました。直ちに古典層からの情報のオーバーフローを受け取るブリッジ（Step 4）の開発に入ることが可能です。
