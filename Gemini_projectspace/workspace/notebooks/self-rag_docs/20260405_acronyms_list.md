# Acronyms & Glossary List (用語・略語集)

この文書は、Self-RAG実験レポート（Tier 1 Execution 等）に登場する主要な専門用語、略語、およびライブラリの意味をいつでも確認できるように整理したものです。

## 1. コア・コンセプト (Core Concepts)
- **RAG (Retrieval-Augmented Generation)**
  検索拡張生成。LLMが回答を生成する前に、外部のデータベースや文書（コーパス）から関連情報を検索・抽出し、それをプロンプトに組み込んでから回答を生成させる技術。ハルシネーション（もっともらしい嘘）を抑える目的で使われます。
- **Self-RAG**
  本リポジトリの主題。モデル自身が「いつ検索すべきか」「検索結果が質問に関連しているか」「生成した回答が事実に基づいているか」を自己評価（Critique）する特殊なトークンを出力しながら生成を行う、高度なRAGフレームワークです。
- **LLM (Large Language Model)**
  大規模言語モデル。GPT-3.5やLlama 2など、膨大なテキストデータで事前学習された汎用的なAIモデル。
- **I/O (Input/Output)**
  入力と出力。本実験では、「どのようなデータ（JSONやTSV）をプログラムに与え、結果としてどのようなデータが出力されるか」というデータの流れ（データフロー）を指します。
- **Embedding (エンベディング/ベクトル化)**
  自然言語（テキスト）を、コンピュータが計算可能な連続した数値の配列（ベクトル）に変換すること。意味が似ている文章は、ベクトル空間上で近い距離に配置されます。
- **Fallback (フォールバック)**
  システム障害やエラーが発生した際に、システム全体を停止（クラッシュ）させるのではなく、代替となる安全な処理（エラーメッセージの出力やデフォルト値の返却など）を行って機能を維持する設計のこと。

## 2. アルゴリズム・アーキテクチャ (Algorithms & Architectures)
- **FAISS (Facebook AI Similarity Search)**
  Meta（旧Facebook）が開発した、高次元ベクトルの類似度検索とクラスタリングを極めて高速に行うためのライブラリ。大量のエンベディングベクトルの中から、クエリに最も近い（内積スコアが高い）ベクトルを探し出します。
- **Contriever / Bi-encoder (双方向エンコーダ)**
  検索クエリと対象文書を、それぞれ独立した同じエンコーダ（ネットワーク）に通してベクトル化し、最後にそれらの内積で関連度を計算するアーキテクチャ。高速なマッチング（FAISS等での事前計算）に適しています。
- **Exact Match (EM)**
  モデルの出力テキストが、人間が用意した正解（Golds）のテキストと「一文字の狂いもなく完全に一致しているか」を判定する厳格な評価指標（文字列一致メトリクス）。

## 3. 環境・インフラ (Environment & Infrastructure)
- **VRAM (Video RAM)**
  GPU（グラフィックボード）に搭載された専用のメモリ。LLMを動かすための巨大なパラメータや計算途中のデータ（テンソル）を保持するために必須で、これが不足すると `Out Of Memory (OOM)` エラーでプログラムが強制終了します。
- **venv (Virtual Environment)**
  Pythonの標準機能で作成する「仮想環境」。システム全体のパッケージ環境を汚すことなく、特定のディレクトリ内だけで独立したパッケージ（ライブラリ）のインストールと実行領域を作ることができます。
- **HuggingFace**
  AIモデルやデータセットが共有されている世界最大のオープンソースプラットフォーム。本実験の `facebook/contriever` などもここから自動ダウンロードされます。
- **vLLM / DeepSpeed / FlashAttention**
  LLMの推論処理や学習を劇的に高速化・省メモリ化するための高度な計算最適化ライブラリ。ただし、環境への導入には特定のCUDAバージョンを用いた難度の高いC++コンパイルが要求されるため、ローカル縛りのある環境では導入障壁になりやすいです。

## 4. データフォーマット (Data Formats)
- **JSON (JavaScript Object Notation)**
  キーと値のペアで構成される、人間にも機械にも読みやすい標準的なデータ記述言語。`dummy_queries.json` などで使用。
- **JSONL (JSON Lines)**
  1行ごとに独立した1つのJSONオブジェクトが記述されたテキストファイル。巨大なデータセットを扱う機械学習分野で、ファイル全体をメモリに展開せず1行ずつ読み込んで処理(ストリーミング)するのに適しています。`dummy_eval_data.jsonl` などで使用。
- **TSV (Tab-Separated Values)**
  データをタブ（Tab）文字で区切って表形式で保存したテキストファイル。`dummy_corpus.tsv` などで使用。
- **Golds / Answers**
  評価データセットにおいて、「人間が用意した模範解答（Ground Truth）」のこと。モデルの出力をこれと突き合わせて採点します。
