# Dynamic Alpha (Hebb的ゲート) プロトタイプ実装計画

## Goal Description
量子層（Langevin連続アトラクタモデル）において、固定された α（外部注入の強さ）が引き起こす「カタストロフィック忘却のジレンマ」を解決するための **Dynamic Alpha（動的アルファ制御）** を設計、実装、および検証します。

これまでの実験で、すべての入力を同じ α で処理すると、強い力で上書きされ過去の記憶が消滅するか、弱い力すぎて直近の記憶が残らないという問題が証明されました。人間の脳におけるHebb則（強く発火した神経細胞の結合は強まる）や、LLMのアテンションスコアの仕組みを模倣し、**「重要な入力文章」のみを強い力（α_signal）で状態ベクトルに刻み、「単なる背景雑話」は弱い力（α_noise）で吸収させるゲート機構**を構築します。

これにより、「何ターン経過しようとノイズに邪魔されない頑健な文脈記憶」と「直近の重要な事実は確実に現在のアトラクタとする」ことの両立（Lossless Context）を達成します。

## 変更対象ファイル（Prototype Sandbox内）

### `retrieval_lm/experiments/phase16_dynamic_alpha/` フォルダを新規作成
このフォルダ直下に、本機構のプロトタイプとなる Python スクリプト群を格納します。

### [NEW] `dynamic_alpha_prototype.py`
以下の拡張を加えた Langevin状態空間クラスとテストコードを記述します。

1.  **`LangevinState.update()` の拡張**
    *   `is_signal: bool` というフラグ（重要度判定ゲート）を引数に追加。
    *   `alpha = 0.5 if is_signal else 0.01` として、入力情報の重要度に応じてベクトルへの注入力をダイナミックに可変させるHebb的ゲートを実装。
2.  **Hebb的ゲート（Attention代替機）のモック**
    *   本来のシステム（フェーズ17予定の古典層ブリッジ）では、LLMのアテンションウェイトや自己発火（Self-RAGなどのRetrieval要求）の有無によって `is_signal` を判定させます。
    *   本プロトタイプでは、テスト対象の「Target A」と「Target B」の注入時のみ意図的に `is_signal = True` とし、998ターンの背景ノイズは `is_signal = False` と扱います。

## Verification Plan (検証フェーズの計画)
本機構が意図通りに動作するかを証明するため、以下のシミュレーションを実行します。

### Automated Tests (検証シミュレーション)
1.  **フェーズ15.8（英語版v1/v2）で用いた128パターン検証の再実行**
    *   Target A（Turn 1）とTarget B（Turn 900）に `is_signal=True` を適用して実行。
    *   期待される結果としては、αの増減によるジレンマから解放され、Target A（古い記憶）がノイズに負けることなく強固に（例：Score 0.3以上で）生存しつつ、Target B（最新の記憶）はTarget Aをわずかに上回ってアトラクタのトップ（例：Score 0.5以上）に君臨する、という**「共存・両立」**のグラフが描画されるはずです。

2.  **相関グラフの出力**
    *   `Dynamic Alpha: Base Sim vs Final Score` のプロットを出力。過去のレポートのグラフ（AとBが完全に重なってしまっていたもの）と比較し、**「Aの生存ライン」と「Bの最新優先ライン」が平行に分離する（究極のV字の片側）**ことを視覚的に証明します。
