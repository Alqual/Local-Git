# 概念設計書：忘却・記憶・連想のハイブリッド・メカニズム

**作成日**: 2026-04-13
**目的**: 本アーキテクチャにおけるAIの認知プロセス（記憶、忘却、連想）を概念的に整理し、それぞれに最適な物理モデル（Langevin方程式を中心とするハイブリッド方程式群）をどのように組み合わせていくか、その将来的な設計の透明性を確保する。

---

## 1. 全体コンセプト
人間の脳（およびLLMが目指すべき高度な文脈理解）において、「忘れること」と「思い出すこと」は単一のルールでは動きません。
話題は滑らかに移り変わることもあれば、突然飛躍することもあります。本設計では、これらの認知プロセスを以下の3つに分解し、それぞれに合致する物理方程式をハイブリッドで適用（または観測）していくことを基準とします。

## 2. 認知プロセスと物理モデルのマッピング

### A. 記憶（Memory / Retention）
「経験した情報を空間に刻み込み、保持するプロセス」

*   **認知プロセス**: 新しい知識や会話が、既存の背景知識の上に積み重なっていく。
*   **適用モデル**: **ヒルベルト空間上の状態ベクトル（重ね合わせ）**
*   **メカニズム概要**:
    全てのKVキャッシュから溢れた文脈は、384次元空間上のベクトルとして現在の「状態ベクトル $S$」に足し合わせ（線形結合）られます。この時、動的$\alpha$（Hebb的ゲート）によって、重要な記憶（シグナル）は深く刻まれ、背景雑話（ノイズ）は浅く刻まれます。

### B. 忘却（Forgetting / Dissipation）
「時間が経つにつれて、あるいは話題が変わるにつれて、古い情報が背景に沈むプロセス」
忘却には「滑らかなフェードアウト」と「突発的なリセット」の2種類が存在します。

*   **B-1. 滑らかな忘却（時間の経過に伴う自然な記憶の薄れ）**
    *   **適用モデル**: **過減衰Langevin方程式（散逸項 $\mu$）**
    *   **メカニズム概要**: ひとつの話題が長く続いている間、古い発言はインクが水に溶けるように、背景のノイズへ向かってなだらかに原点回帰（散逸）していきます。現在実装・完了済みのコア・メカニズムです。
*   **B-2. 突発的な忘却（話題の劇的な転換によるリセット）**
    *   **適用モデル**: **レヴィ飛躍（Lévy Flights / クラマース・モヤル展開）**
    *   **メカニズム概要**: 「ところで話は変わるけど」といった強烈なコンテキスト・スイッチが発生した瞬間、通常のガウスノイズではなく異常拡散（大きなジャンプ）を状態ベクトルに強制適用し、古い文脈の引力を一瞬で断ち切ります。

### C. 連想（Association / Retrieval）
「特定のキッカケによって、沈んでいた記憶が復元されたり、複数の情報が結びつくプロセス」
連想には「外部からの引き出し」と「内部での自然な結びつき」の2種類があります。

*   **C-1. 外部クエリによる直接連想（思い出し）**
    *   **適用モデル**: **ボルンの規則 / 波動関数の収束（Collapse）**
    *   **メカニズム概要**: ユーザーから「あれって何だっけ？」と直接問われた際、そのクエリが状態ベクトル $S$ を「強力な検索アトラクタ」へと変貌させます。内積（コサイン類似度）を計算することで、忘却の底（Archive）から正確なターゲット情報を一本釣りで引き揚げます（フェーズ17で実証済み）。
*   **C-2. 内部の自発的な連想と同調（アイデアのひらめき・要約）**
    *   **適用モデル**: **蔵本モデル（Kuramoto Model / 位相同期）または ホップフィールド・ネットワーク**
    *   **メカニズム概要**: ユーザーが直接質問しなくとも、会話の中で特定のキーワードや関連トピックが「3回以上」かすった時など、空間内に散らばっていた古い文脈ベクトルたち（Archive内の記憶）が互いに共鳴・同期を始めます。「メインテーマ」という巨大なアトラクタ盆地が自発的に形成され、LLMに対し「これに関する要約を裏で生成すべき」というシグナルを送ります。

## 3. 今後のハイブリッド統合イメージ（80%完成を目指して）

これからの基礎実験や開発において、上記の方程式群は以下のようなパイプラインで自動的に調停・合成される姿を理想とします。

```text
[ユーザーのプロンプト入力]
       │
       ▼
 1. LLM推論パイプライン（実数空間のコサイン類似度計算）
       │
       ├─ (トークン溢れ) ─▶ [Archiveへテキスト保存]
       │
       ▼
 2. 状態ベクトル $S$ の更新（Langevin方程式ベース）
       │
       ├─ 判断A: 話題が連続しているか？
       │      YES ─▶ 【滑らかな忘却】(Langevinのガウスノイズと散逸 μ を適用)
       │      NO  ─▶ 【突発的な話題転換】(レヴィ飛躍による大きなノイズジャンプを適用)
       │
       ├─ 判断B: 何か思い出すべきか？
       │      YES ─▶ 【クエリ連想】(波動関数CollapseでArchiveから抽出してLLMへ注入)
       │      NO  ─▶ 【自発的同期】(蔵本モデルが裏で回り、メインテーマの位相を監視)
       │
       ▼
[次の推論へ向けて無限にループ]
```

## 4. 総括
現在は「滑らかな忘却（Langevin）」と「クエリ連想（Collapse）」という最も基本的かつ強力な主軸が完成しています。
今後の基礎実験においては、現在のLangevinモデルの限界（例えば、話題が急に飛んだのに以前の文脈を引きずりすぎてLLMが混乱するケース等）を意図的に探し出し、そこに「レヴィ飛躍」や「蔵本モデル」といった追加の物理法則モジュールをプラグインとして組み込んでいくことで、システムの完成度を30%から80%へと劇的に引き上げることが可能です。
