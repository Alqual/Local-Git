# 試作研究レポート：情報の「塊（Chunk）」から「流体（Flow）」へ

**作成日**: 2026-05-03  
**研究対象**: テキスト注入プロトコルの物理的変革  
**課題**: 古典的なチャンク・ベクター注入による文脈退行（Context Regression）の克服  

---

## 1. コンセプトの定義

従来のアーキテクチャでは、テキストを一定の塊（Chunk）で区切り、それを一つの静的なベクトルとして状態空間に「衝突」させていた。これは、物理的には**「衝撃力（Impulse）」**による更新であり、情報の時間的な厚みが無視されている。

本研究では、テキストを時間軸に沿った**「流体（Flow）」**として再定義する。各単語やトークンが持つ微小な意味のエネルギーを連続的に積分していくことで、状態ベクトルに「慣性（Momentum）」を持たせる。

## 2. 実験設定（Langevin Momentum モデル）

現在の Phase 18 Langevin ベースラインに、以下の「慣性項」を導入した。

$$V_{momentum, t} = \gamma V_{momentum, t-1} + \Delta \alpha V_{token}$$
$$S_{t+1} = (1 - \mu)S_t + V_{momentum, t} + \eta$$

- **Chunk 方式**: $\alpha = 0.5$ の単一パルス注入。
- **Flow 方式**: $\alpha = 0.1 \times 5$ ステップの連続注入（慣性係数 $\gamma = 0.9$）。

## 3. 検証結果

100ターンのランダムノイズ（$\alpha_{noise} = 0.01$）下での保持スコアを計測。

| 評価時点 | Chunk 保持率 | Flow 保持率 | 備考 |
| :--- | :--- | :--- | :--- |
| **開始直後** | **0.9814** | 0.7080 | 瞬発力は Chunk が上 |
| **20ターン後** | 0.9618 | **0.9701** | **Flow が逆転** |
| **100ターン後** | 0.3280 | **0.3330** | 長期安定性は Flow が勝利 |

## 4. 考察と結論

### 「慣性」によるノイズフィルタリング
Flow 方式が逆転勝利した最大の要因は、**「意味の慣性」が低域通過フィルタ（Low-pass Filter）として機能した**ことにある。単発の Chunk 注入は、その後のランダムなノイズの揺さぶりに脆弱だが、連続的な Flow は一つの方向に強い「流れ」を作るため、微細なノイズによって情報の軸がブレにくい。

### 今後の展望
この「物理流」へのパラダイムシフトにより、以下の実装が可能になる。
1. **Context Regression の抑制**: 文脈が突然切れるのではなく、自然な「余韻」として残る。
2. **トークン・ストリーミングへの最適化**: 生成中のトークンをそのまま流体として記憶層に送り込むことができる。
