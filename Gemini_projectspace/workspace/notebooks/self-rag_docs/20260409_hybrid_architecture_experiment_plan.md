---

## 1. 背景と問題意識

### 現在のAI（KVキャッシュ型）の限界

現在の主流LLM（GPT, Claude, Gemini等）は、入力として与えられた全トークンを **KVキャッシュ（Key-Value Cache）** として線形に保存する方式を採用しています。この方式は**「構文的無損失（Syntax Lossless）」**を実現していますが、その代償として2種類の根本的な限界を抱えています。

| 限界の種類 | 内容 |
|---|---|
| **量的限界（トークン爆発）** | メモリ消費がトークン数に比例して増大し、VRAMが物理的に飽和する |
| **観測限界による不連続な消滅** | コンテキストウィンドウの端に達した瞬間、情報が完全かつ突然に消滅する（不自然な忘却） |

これらは**古典的な情報理論に基づく0か1かのパラダイム**の限界であり、本研究の出発点です。

## 3. 実施済みの実験フェーズ（Phase 1〜14）

### Tier 1-2: 古典的アーキテクチャ（Phase 1〜3）
- ✅ ステートレス推論エンジン（TinyLlama）の実装
- ✅ 文字列バッファ型コントローラの構築
- **結論**: 長文になるとAttention崩壊が発生（Semantic Loss）

### Tier 3: 量子化基礎実験（Phase 4〜8）
- ✅ 入力の埋め込みベクトル量子化と状態ベクトルの重ね合わせ
- ✅ 1000ターン・大量ノイズ下での意味論的無損失の実証
- ✅ ターン距離がスコアに影響しないことの確認（時間フラット問題の発見）

### 時間モデルの探索（Phase 9〜13）
- ✅ 均一減衰（Phase 9）→ 最近の記憶が優先される自然な忘却
- ✅ 不均一（異方性）減衰（Phase 10）→ S/N比の崩壊によって定常性が得られないことを確認
- ✅ RoPE円形回転（Phase 11）→ 定常回転では時間区別が生まれないことを確認
- ✅ 楕円回転（Phase 12）→ 非対称スケールで若干改善（Ratio: 1.02→1.04）
- ✅ 時間性付きKV型RoPE（Phase 13）→ 相対位相差による初の時間区別実現（Ratio: 2.0）

### 物理運動モデルの比較（Phase 14）
- ✅ 4種モデル（減衰振動子・Langevin・Fokker-Planck・Lindblad）のシミュレーション
- **主要発見**: LangevinとLindbladが最も強い時間区別（Ratio ~1.5）を示す
- **理論的結論**: 確率的揺らぎ（散逸）が時間の矢を生み出す本質的機構である

## 4. 次期実験計画

### Step 3: 量子層の散逸モデルの選定と最適化

**目的**: Phase 14で最も性能が高かった **Langevin / Lindblad** のパラメータ最適化

**検証するパラメータ**:
| パラメータ | 候補値 | 意味 |
|---|---|---|
| μ（Langevin摩擦） | 0.01〜0.1 | ドリフトの速さ（忘却率） |
| σ（Langevin拡散） | 0.005〜0.05 | 確率的揺らぎの強度 |
| γ_deco（Lindblad散逸） | 0.01〜0.05 | デコヒーレンス強度 |
| 次元数 | 384, 768 | 情報容量 |

**搭載すべき追加機能（Hebb的ゲート）**:
```
重要度 = Attentionスコア または 文の繰り返し頻度
→ 重要度が高いベクトルは σ（揺らぎ）を小さくして保護する
→ 重要度が低いベクトルは σ を通常値（揺らぎに飲まれやすく）
```

### Step 4: 古典層→量子層 ブリッジの実装

**目的**: KVキャッシュが溢れた瞬間、その情報を Layer 2 に転送するプロトコルの構築

**実装方針**:
```python
if current_token_count > WINDOW_THRESHOLD:
    # 消滅予定のトークン群を埋め込みベクトルに変換
    overflow_text = get_oldest_tokens(n=50)
    overflow_vector = encoder.encode(overflow_text)
    
    # Layer 2 の状態ベクトルに加算（Langevin/Lindblad的更新）
    quantum_state.update(overflow_vector)
    
    # 古典層から削除
    drop_oldest_tokens(n=50)
```

**検証指標**:
- 古典層にある間：正確な文字列での参照が可能か
- 古典層から消えた後：量子層からのCollapse抽出で意味が保持されるか

### Step 5: End-to-Endテスト

**目的**: 実際の会話シナリオで 2層ハイブリッドが有効に機能するかの検証

**テストシナリオ**:

3. 300ターン後に「彼の大好物は？」とクエリし、Layer 2 から Collapse 抽出できるか確認

---

### Step 6: 選択的ゲート（Hebb的強化フィルタ）の実装

**目的**: すべての情報を等しく散逸させず、重要なシグナルだけを揺らぎから保護する

**実装候補**:
- Attentionスコアを重要度指標として利用
- 繰り返し参照された情報の揺らぎ係数を減衰（Hebb的学習）
- これにより「情報の選択的な長期保存」が実現する
