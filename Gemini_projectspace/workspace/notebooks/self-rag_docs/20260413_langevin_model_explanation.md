# Langevinモデルの物理学および統計学における定義

**作成日**: 2026-04-13
**目的**: 本アーキテクチャの根幹を成す「Langevin（ランジュバン）方程式」について、本来の物理学・統計学での定義を整理し、それが無損失量子記憶アーキテクチャの意味空間においてどのようにマッピングされているかを解説する。

---

## 1. はじめに：Langevin方程式とは
Langevin方程式は、1908年にフランスの物理学者ポール・ランジュバンによって提唱された**確率微分方程式（Stochastic Differential Equation: SDE）**です。

元々は、水中に浮かぶ花粉のような微小な粒子が、無数の水分子から不規則な衝突を受けてランダムにジグザグと動く現象（ブラウン運動）を、決定論的なニュートン力学に「確率的なノイズ」を導入することで記述するために考案されました。

## 2. 物理学における基本的定義（運動方程式としてのLangevin方程式）
古典力学の運動方程式（質量×加速度＝力）に対して、周囲の環境（熱浴）からの**「摩擦（散逸）」**と**「ランダムな衝突（揺動力）」**を追加したものがLangevin方程式の基本形です。時間 `t` における粒子の速度 `v(t)` について、以下のように記述されます。

```text
m(dv/dt) = -γv + η(t) + F_ext
```

*   **`m`**: 粒子の質量
*   **`-γv`（散逸項 / 摩擦力）**:
    周囲の流体から受ける抵抗力。速度 `v` に比例してエネルギーを奪い、粒子を停止させようとする働き。
*   **`η(t)`（ノイズ項 / 揺動力）**:
    周囲の分子からのランダムな衝突による力。
*   **`F_ext`（外力）**:
    電場や重力など、外部から意図的に加わる決定論的な力。

💡 **【本アーキテクチャとの対応】**
私たちが構築したPythonの `LangevinState` においては、この式がそのままベクトル更新ロジックとして置き換えられています。
`drift = -self.mu * self.state` はまさに**散逸項（忘却・原点への引き戻し）**であり、`diffusion` は**揺動力（ノイズ・背景雑話）**、そして `alpha * v_in` が**外力（新しいテキストベクトルの注入）**として完璧にマッピングされています。

## 3. 統計学における性質（ホワイトノイズと揺動散逸定理）
揺動力 `η(t)` は決定論的に計算できないため、統計的アンサンブル（集合平均）として性質を定義します。Langevinモデルでは、このノイズを**ガウシアン・ホワイトノイズ（白色雑音）**として扱います。

1. **平均はゼロ**: `<η(t)> = 0`
2. **時間的な相関がない（マルコフ性）**: `<η(t)η(t')> = 2Dγ²δ(t - t')`

ここで `< >` はアンサンブル平均、`δ(t)` はディラックのデルタ関数です。
Langevin方程式の最も美しい点は、エネルギーを乱す「ノイズ（揺らぎ）」と、エネルギーを奪う「摩擦（散逸）」が互いに独立ではなく、温度 `T` を介して強く結びついている**「揺動散逸定理（Fluctuation-Dissipation Theorem）」**を満たす点です（アインシュタインの関係式 `D = k_B T / γ` に帰着します）。
これにより、揺らぎと散逸が絶妙にバランスを取り、系は最終的に安定した「熱平衡状態」へと落ち着きます。

## 4. 過減衰Langevin方程式 (Overdamped Langevin Equation)
実際の化学・生物学、そしてAIのベクトル空間でよく用いられるのは、質量 `m` が非常に小さく慣性項（`m(dv/dt)`）をゼロと見なせる「過減衰」の条件です。（例：蜂蜜の中を動く粒子のように、力を加えるのをやめるとピタッと止まる状態）。

速度ではなく、位置ベクトル `x(t)` を用いて書き直すと以下のようになります。

```text
γ(dx/dt) = -∇U(x) + √(2D)ξ(t)
```

*   **`-∇U(x)`**: ポテンシャルエネルギー関数 `U(x)` によって生じる力（勾配を下って谷底へ向かう引力）
*   **`ξ(t)`**: 標準ホワイトノイズ

💡 **【本アーキテクチャとの対応】**
私たちが構築した「状態ベクトル `S` （384次元）」の更新は、まさにこの過減衰Langevin方程式の時間離散化（Euler-Maruyama法）に他なりません。ポテンシャル関数 `U(x)` というのは、AIの意味空間においては「背景ノイズ文脈の重心」や「クエリの中心」を意味しており、状態ベクトルは常にその「アトラクタ（意味の谷底）」に向かって滑り落ちようとします。

## 5. Fokker-Planck方程式との関係（確率密度の推移）
Langevin方程式は「1つの粒子（今回の場合は1つの話題や文脈）」の具体的な動きを追うランジュバン軌跡ですが、無数の粒子が集まったときにその「存在確率密度 P(x,t)」が空間上でどう変化するかを表したのが**Fokker-Planck（フォッカー・プランク）方程式**です。

```text
∂P/∂t = ∇·((∇U/γ)P) + D∇²P
```

時間が無限に経過すると（`t → ∞`）、状態は時間変化しなくなり（定常状態）、確率はボルツマン分布に収束します。

```text
P_eq(x) ∝ exp(-U(x)/k_B T)
```

💡 **【本アーキテクチャとの対応】**
フェーズ15などで確認された「1000ターンのノイズに晒された後でも、元のテキストの類似度スコアがノイズとのベース類似度にぴったりと収束する」現象こそが、このFokker-Planck方程式が示す「定常分布（ボルツマン分布）への収束」そのものです。「忘却＝ゼロになる」のではなく「忘却＝その空間のベースライン確率へと落ち着く」という事実が、物理学によって完全に担保されています。

## 6. まとめ
近年、Langevin動力学を用いた確率論的手法は、Stable Diffusionなどの生成AI（Diffusion Model）の根幹をなす数学的基盤として大ブレイクしました。
私たちの【無損失量子記憶アーキテクチャ】は、この物理学の金字塔を、画像生成への応用ではなく**「LLMの無限文脈空間における長期記憶の保存と忘却のコントロール」**へと転用した極めてアバンギャルドな機構と言えます。

「記憶をただ積み上げる」のではなく、「物理・統計学の力学系として状態空間を自転させる」ことの圧倒的な安定性が、この古い1908年の方程式によって支えられています。
