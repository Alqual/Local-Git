## 1. プロトタイプのコンセプト

本試作スクリプトは、ハイブリッドアーキテクチャの心臓部である**「量子層（Layer 2）」の挙動を単体でシミュレーション・最適化する**ためのプログラムです。

古典層（KVキャッシュ）から溢れたテキスト情報は、SentenceTransformerによって384次元のベクトルに圧縮されます。本プロトタイプでは、この高次元ベクトル空間上で複数の情報を重ね合わせる際、単なる足し算ではなく**「Langevin方程式（物理学的な確率的散逸モデル）」**を適用しています。

### Langevin更新式（スクリプト内実装）
```python
# 1. 散逸ステップ (Drift + Diffusion)
drift = -self.mu * self.state  # ドリフト項：古い記憶全体の緩やかな薄れ
diffusion = np.random.normal(0, self.sigma, self.state.shape) # 拡散項：ランダムな熱揺らぎ
self.state += (drift + diffusion)

# 2. 吸収ステップ
self.state += v_in             # 新しい情報の重ね合わせ

# 3. 射影（ノーマライズ）
self.state /= np.linalg.norm(self.state)
```
目的は、**μ（摩擦係数：忘却スピード）**と**σ（拡散係数：揺らぎ強度）**を最適化し、ベクトルが「古い情報ほど弱く、新しい情報ほど強く」共鳴する状態空間（時間の矢）を人為的に作り出すことです。

## 2. 実装の背景となる既存研究（系譜との接続）

本プロトタイプの構築には、以下の「枯れた技術」と「最新理論」のハイブリッドな視点が組み込まれています。

### ① Holographic Reduced Representations (HRR) [Plate, 1995]
*   **適用点**: 固定次元（384次元）の連続空間上に、複数の意味的ベクトルを「加算」によって重畳（Superposition）させる基礎理論として機能しています。

### ② SGLD (Stochastic Gradient Langevin Dynamics) [Welling & Teh, 2011]
*   **適用点**: 機械学習においてLangevin動力学は主に「局所最適解からの脱出（学習手法）」として使われますが、本プロトタイプではそれを**「記憶空間における自然な時間経過・自然忘却のメカニズム」**として転用しています。ノイズ（Diffusion）が蓄積することで、古いベクトル成分のS/N比が自然に削れていく設計です。

### ③ Modern Hopfield Networks [Ramsauer et al., 2021]
*   **適用点**: 毎ターンの最後に状態ベクトルをノーマライズ（単位超球面上への射影）する操作は、このベクトル空間が「連続的アトラクタ（Continuous Attractor）」として振る舞うことを意図しています。後続のCollapse操作で、クエリ入力がこの超球面上の谷（アトラクタ）に引き込まれて連想を生み出す準備となります。

### ④ Infini-Attention [Google, 2024]
*   **適用点（対比）**: 行列記憶への加算による圧縮という点ではGoogleの最新手法と同じですが、あちらが「学習（Backprop）によって得られたゲート重み（β）」で記憶を制御するのに対し、本プロトタイプは「物理法則（Langevin熱揺らぎ）による不可逆な散逸」で自己組織化的に時間を分離しようとする点が全く異なります。

## 3. グリッドサーチ実行結果からの初期考察

スクリプトによるテスト（μ: 0.005～0.2, σ: 0.0～0.05）を実行した結果、非常に興味深い現象が再現しました。

| μ | σ | Score A (1ターン目) | Score B (900ターン目) | Ratio B/A |
|---|---|---|---|---|
| 0.005 | 0.0 | 0.4475 | 0.4176 | 0.9332 |
| ... | ... | ... | ... | ... |
| 0.2 | 0.05 | 0.3359 | 0.3252 | 0.9681 | (最適値)

### 判明した課題：「初頭効果（Primacy Effect）」の強さ
Ratio B/A が 1.0 未満（本来は直近であるBの方が高くなるべきだが、古いAの方がスコアが高い）という結果が出ました。
これはベクトル加算と正規化の数学的性質によるものです。
初期状態（ゼロベクトル）に一番最初に加算された `v_A` が状態ベクトル空間の「主軸」を決定してしまい、後から足される情報は単なる摂動（ノイズ）としてしか働いていない状態です。

### 次のステップへの示唆
Langevinの「忘却（μ）」は機能していますが、最初のベクトルが強すぎるため、**「情報の注入比率（ステップ・サイズ）」を時間経過とともに動的に調整するか、正規化のタイミングと強さを減衰させる修正**が必要です。これが次に行うプロトタイプの改良ポイントになります。
